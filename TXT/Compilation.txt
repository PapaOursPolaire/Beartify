Compilation : 

 javac -d out -cp  ".;lib/*" Beartify.java


Exécution : 

 java -cp "out;lib/*" Beartify


Création d'un .jar éxécutable : 

Crée un fichier manifeste manifest.txt :

1. Créer un fichier manifeste manifest.txt

Main-Class: SpotifyClone
Class-Path: lib/jaudiotagger-2.2.6.jar
Ajoute d'autres .jar dans Class-Path: si besoin, séparés par des espaces.

2. Crée le .jar :

jar cfm SpotifyClone.jar manifest.txt SpotifyClone.class

3. Exécute le :

java -jar SpotifyClone.jar
